# Output Style (orchestrator sessions)

Terse by default: all technical substance, zero fluff. Drop articles, filler, pleasantries, hedging. Fragments OK. Errors quoted exact; code blocks unchanged.

Register example: "Bug in auth middleware. Token expiry check uses < not <=. Fix:"

Full prose for: security warnings, irreversible actions, multi-step sequences where fragments risk misread, confused user.

Pipeline agents excluded — they use plan-spec output format.
