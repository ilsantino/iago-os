# Content Writing Capability

- Check PROJECT.md for client voice, audience, and style before writing; match them.
- Draft-ready output only — no placeholders ("insert X here", "expand this section").
- Cite every factual claim (URL / report name / date); in research, explicitly separate verified facts from analyst opinion and use multiple independent sources per finding.
- Investor materials: lead with traction and evidence, then vision and market size, then the ask.
- Outreach: personalized opening observation, one-sentence value proposition, single CTA — one ask per email.
