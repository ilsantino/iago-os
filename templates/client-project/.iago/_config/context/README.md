# `_config/context/`

Stable framing that is neither a decision nor a plan: voice and tone, client
vocabulary, integration briefs, handoff notes, asset manifests.

Framing scoped to one feature does not belong here — it goes in that feature's
`plans/feature-{slug}/SPEC.md` and dies with the feature.

L3 — configured once, edited rarely, read as a constraint.
